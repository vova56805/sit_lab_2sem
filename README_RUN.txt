Как запустить:

1. Распаковать архив в папку без кириллицы и пробелов, например C:\react\practicum_mui_pages_dndkit_vite
2. Открыть PowerShell в этой папке.
3. Выполнить:
   npm install
   npm start
4. Открыть адрес, который покажет терминал. Обычно это http://127.0.0.1:5173/
5. Страница лабораторной работы: http://127.0.0.1:5173/testing

Проект сделан на React + TypeScript + MUI + DndKit + Redux Toolkit.
