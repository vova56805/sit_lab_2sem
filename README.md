# practicum_mui

Готовая лабораторная работа «Создание HTML-страницы — TypeScript, React и библиотека MUI».

## Запуск

```bash
npm install
npm start
```

После запуска проект откроется на `http://localhost:3000/`.

## Что реализовано

- адаптивная навигационная панель;
- свернутое меню через Drawer;
- активный пункт меню через prop `active`;
- выделение активного пункта и hover-цвет в Drawer;
- адаптивная masonry-галерея с подписями;
- основной контент из четырех карточек;
- компонент `StyledTypography` для описаний;
- разный порядок изображения и текста в карточках;
- футер.
