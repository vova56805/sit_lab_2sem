# practicum_mui_pages

Лабораторная работа «Создание многостраничного сайта — TypeScript, React и MUI».

## Запуск

```bash
npm install
npm start
```

Страницы:

- `/` — Главная;
- `/list` — Список зданий;
- `/building/:id` — описание здания из галереи;
- `/chart` — сгруппированные данные и интерактивные диаграммы.
